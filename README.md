# Clinical-Trial-Disease-Category-Classification
# Project Overview
The main objective is to process clinical trial text data, clean and preprocess medical summaries, perform exploratory data analysis (EDA) and implement an end-to-end NLP pipeline and deployed through an interactive Streamlit web application.
# Objectives
Apply NLP preprocessing techniques
Perform tokenization, stop-word removal, and lemmatization
Analyze clinical trial data using Exploratory Data Analysis
Identify common disease categories and medical keywords
Convert medical text into numerical features using TF-IDF
Build Machine Learning models for disease classification
# Technologies Used
Python
Regular Expressions
Tokenization
Stop Word Removal
Lemmatization
TF-IDF Vectorization
Scikit-learn
